# AA Designs — Website

Brand-new AA Designs site built from the approved poster (`../aadesigns-main/brand/aa-designs-poster-APPROVED.png`).

- React + Vite + TypeScript, deployed on Vercel
- Pages: Home, About, Services, Portfolio, Contact
- Contact form delivers to contact@aa-designs.com via FormSubmit (first submission sends a one-time activation email)

## Vercel settings
- Root Directory: `aa-designs-site`
- Framework preset: Vite (build `npm run build`, output `dist`)
